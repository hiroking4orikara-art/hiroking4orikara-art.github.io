教科を選ぶ

中学技術・家庭のweb教科書

木工・金属、栽培、発電・電気回路、情報セキュリティ、子どもの成長、栄養と調理、衣服、住まい、契約・エシカル消費の要点をマスターしよう！

1. 技術分野

木工・金属加工の設計や工具の使い方、作物の栽培計画、電気や機械の仕組み、情報の活用とセキュリティを学びます。

単元1: 材料と加工の技術

木材のまさ目・板目、木表・木裏、木質材料の分類から、金属・プラスチックの性質、製図、のこぎりやかんな等工具の正しい使い方を整理します。

コラムを読む ➔

単元2: 生物育成の技術

種まきの方法、間引きや誘引、摘芽・摘心などの管理作業、土壌の団粒構造、肥料の三要素（窒素・リン・カリ）、連作障害や養殖・栽培漁業を解説します。

コラムを読む ➔

単元3: エネルギー変換の技術

発電方式（コンバインドサイクル等）、周波数（50/60Hz）、電気回路（短絡・漏電）、ブレーカーやアース線、リンク機構やカム、ベアリングなどの機械要素を整理します。

コラムを読む ➔

単元4: 情報の技術

コンピュータの5大装置、LANやIPアドレス、双方向性コンテンツ、プログラムの基本構造（順次・分岐・反復）、セキュリティ対策や知的財産権について解説します。

コラムを読む ➔

2. 家庭分野

家族の機能や子どもの発達、高齢者との共生、栄養バランスと調理、衣服の管理と製作、住環境の安全、スマートな消費生活を学びます。

単元5: 家族・高齢者と子どもの成長

家族の役割や自立、乳幼児の身体・情緒発達の特徴、基本的生活習慣と社会的生活習慣、伝承遊びや子どもの権利、共生社会の取り組みを解説します。

コラムを読む ➔

単元6: 高齢者との関わりと共生

高齢者の身体的特徴（肺活量・筋肉の衰え等）、安全な立ち上がり介助や歩行介助の基本、超高齢社会の現状と地域共生社会の重要性を学びます。

コラムを読む ➔

単元7: 食生活と栄養、調理の基本

五大栄養素と6つの基礎食品群、一汁三菜の献立、旬や消費期限・アレルギー表示、食中毒予防三原則、地産地消・食品ロス、計量や下ゆで等の調理の基本を整理します。

コラムを読む ➔

単元8: 衣生活と衣服の手入れ、製作

衣服のT.P.Oやクールビズ、天然繊維と合成繊維、界面活性剤や洗濯表示、衣服の製作プロセス（地直し・裁断・まつり縫い等）やミシンの使い方を解説します。

コラムを読む ➔

単元9: 住生活と住まい方の工夫、安全

住まいの空間（LDK）や動線計画、畳の特徴、家庭内事故の防止（バリアフリー・ユニバーサルデザイン）、シックハウスや一酸化炭素中毒対策、家具の固定を解説します。

コラムを読む ➔

単元10: 消費生活と持続可能な社会

物資とサービス、売買契約と未成年者取消権、支払い方法（クレジットカード等）、クーリング・オフ制度やPL法、エシカル消費や課題解決プロセスを整理します。
