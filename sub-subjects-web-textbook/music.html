教科を選ぶ

中学音楽のweb教科書

歌唱曲・鑑賞曲・楽典の要点を整理して、定期テストで高得点を目指そう！

1. 歌唱曲

歌唱曲の作詞者・作曲者、拍子や調、歌い方の特徴を整理します。

歌唱曲① (We'll Find The Way・光の道・主人は冷たい土の中に)

杉本竜一、名田綾子、フォスターの作品と、基本的な休符・強弱記号の知識を学びます。

コラムを読む ➔

歌唱曲② (浜辺の歌・赤とんぼ・夢の世界を)

日本を代表する歌曲「浜辺の歌」「赤とんぼ」や、混声合唱曲「夢の世界を」の要点を解説。

コラムを読む ➔

歌唱曲③ (君をのせて・明日を向いて・生命が羽ばたくとき)

「天空の城ラピュタ」でお馴染みの名曲や、中学校の合唱曲の重要ポイント。

コラムを読む ➔

歌唱曲④ (翼をください・夏の思い出・明日を信じて)

「翼をください」のコード進行や合唱、日本の夏の情緒を歌う「夏の思い出」。

コラムを読む ➔

歌唱曲⑤ (荒城の月・サンタ ルチア・花)

滝廉太郎の代表作「荒城の月」「花」や、イタリアのナポリ民謡「サンタ ルチア」。

コラムを読む ➔

歌唱曲⑥ (花の街・早春賦・帰れソレントへ)

戦後の名曲「花の街」や日本の美しい春を歌う「早春賦」、カンツォーネの名曲。

コラムを読む ➔

歌唱曲⑦ (ふるさと・unlimited・マイ バラード)

唱歌「ふるさと」や、合唱の定番曲「マイ バラード」の構成と強弱記号。

コラムを読む ➔

歌唱曲⑧ (大切なもの・時の旅人・蛍の光)

卒業式や合唱コンクールの定番曲「大切なもの」「時の旅人」の重要要素。

コラムを読む ➔

歌唱曲⑨ (HEIWAの鐘・椰子の実・旅立ちの日に)

沖縄生まれの合唱曲「HEIWAの鐘」や、卒業式の決定版「旅立ちの日に」。

コラムを読む ➔

歌唱曲⑩ (大地讃頌・仰げば尊し)

混声合唱組曲の金字塔「大地讃頌」の各パートの役割や、伝統的な卒業ソング。

コラムを読む ➔

2. 鑑賞曲

西洋音楽・日本の伝統音楽の名曲の構造や背景、使われている楽器を学びます。

鑑賞曲① (春・魔王・雅楽「越天楽」)

ヴィヴァルディの「春」、シューベルトの「魔王」、日本の雅楽の代表曲「越天楽」を解説。

コラムを読む ➔

鑑賞曲② (箏曲「六段の調」・フーガ・交響曲第5番)

八橋検校の「六段の調」、バッハの「フーガ ト短調」、ベートーヴェンの「運命」を解説。

コラムを読む ➔

鑑賞曲③ (アイーダ・歌舞伎「勧進帳」・文楽)

ヴェルディのオペラ「アイーダ」や、日本の伝統芸能である歌舞伎と人形浄瑠璃を解説。

コラムを読む ➔

鑑賞曲④ (ブルタバ・ボレロ・尺八曲「巣鶴鈴慕」)

スメタナの「わが祖国」より「ブルタバ」、ラヴェルの「ボレロ」、伝統的な尺八の曲を解説。

コラムを読む ➔

鑑賞曲⑤ (能「敦盛」・日本の民謡・ポピュラー音楽)

能の歴史と演目、日本の各地に伝わる民謡の特徴や世界の様々な音楽を解説。

コラムを読む ➔

3. 音楽の知識 (楽典・楽器)

テストに必ず出る、楽譜の読み方や音楽の基礎知識です。

① 記号やリズム

反復記号、変化記号（シャープ・フラット）、様々な音符や休符、拍子の捉え方を整理します。

コラムを読む ➔

② コードや調

C、Amなどの主要なコードネームや、長調・短調の調判定、音階の仕組みを解説します。

コラムを読む ➔

③ 用語や楽器

速度記号や強弱記号、日本および西洋のさまざまな楽器の分類や音色の特徴を解説。

コラムを読む ➔

④ 指揮のしかた・歌いかた

2拍子・3拍子・4拍子の指揮者の手の動きや、腹式呼吸などの発声の基本を整理します。

コラムを読む ➔

⑤ 音楽史

バロック、古典派、ロマン派、近現代に活躍した大作曲家たちの生涯と代表作、日本の芸能史。

コラムを読む ➔

⑥ リコーダー

アルトリコーダーの運指（指使い）や、タンギングなどの演奏技法のポイントを整理します。
